# Cm v0.16.0 リリースノート（開発中）

**前バージョン:** v0.15.1

## 🎯 テーマ: SystemVerilogバックエンドの機能充実

計画の詳細は [v0.16.0 SVバックエンド拡充ロードマップ](../design/v0.16.0/roadmap.html) を参照。

### 予定機能

- モジュールパラメータ `#(parameter WIDTH=8)` と階層化Stage 3（パラメタライズドIP対応）
- `#[sv::pin]` 属性と `--emit-constraints`（Gowin .cst / .tcl の自動生成）
- トライステート（'z）と CDC同期化プリミティブ
- ビットスライス構文（`x[7:4]` / `x[i +: 8]`）
- match式の casez / unique case 写像
- WIDTH系lint警告の解消と `--sv-strict-lint` のデフォルト化
- 非サポート構文（force/specify/UDP等）の明示エラー化

### 変更履歴

#### 2026-07-07: モジュールパラメータと階層パラメータ伝搬（実装設計01）

- **`#[sv::parameter] const`**: `module #(parameter WIDTH = 8)` ヘッダを生成し、
  `bit[WIDTH]` のポート・内部信号幅を記号のまま（`[WIDTH-1:0]`）出力
  （checkerがサイズ参照名を解決後も保持するよう変更）
- **階層でのパラメータ伝搬**: `//! sv: hierarchy` のextern struct自動生成が
  サブモジュールの `#[sv::parameter]` を `#[sv::param]` フィールドとして写し、
  インスタンスのstructリテラル `{ WIDTH: 16, ... }` で上書き可能
  （`#(.WIDTH(16))` を出力。上書き優先のバグ修正含む）
- 自動テストベンチがモジュールパラメータをlocalparamとして写すよう対応
- パーサ: 型サイズの識別子参照（`bit[WIDTH]`）をグローバル宣言の
  先読みが受理するよう修正
- テスト: ユニット（ModuleParameterEmission）+ 統合
  sv/hierarchy/param_top・param_shifter（シミュレーションで
  パラメータ上書きの実効を検証）。SVスイート97件
- チュートリアル: [モジュール階層](../tutorials/ja/compiler/sv/hierarchy.html) に
  パラメータ節を追加（日英）、型ページの注記を更新
- VSCode拡張: 変更なし（属性は既存ルールでハイライト済み）
- 未対応として明記: パラメータ幅メモリ（bit[W][D]）・パラメータ依存ループ展開

#### 2026-07-07: 実機I/O機能（実装設計02・03）

- **`#[sv::pin]` 属性と `--emit-constraints`**: 物理ピン割り当てをポート宣言に
  同居させ、Gowin向け `.cst`（IO_LOC/IO_PORT）と `.tcl`（プロジェクトスクリプト）を
  生成。`//! sv: device:` / `//! sv: option:` ディレクティブでデバイス型番と
  合成オプションを指定。未知の `key: value` は大文字化して素通し
  （ツール固有属性対応）。ピン未指定ポートの警告つき。生成はオプトイン
- **`#[sv::tri(oe:, out:)]`**: トライステート駆動の生成
  （`inout tri` ポート + `assign ... : 1'bz`）。I2C等の双方向バス対応
- **`#[sv::sync(clk:, src:, stages:)]`**: CDC 2FF同期段の宣言的生成
  （`(* async_reg = "true" *)` 属性付き、段数指定可）
- パーサ: 属性の名前付き引数（`key: value`）と整数リテラル引数に対応
- テスト: sv_codegen_test に Tristate / CdcSync を追加（計87件）
- チュートリアル: [実機I/O](../tutorials/ja/compiler/sv/board-io.html) を新設（日英）
- VSCode拡張: 変更なし（`#[sv::pin]` 等は既存の属性ルールでハイライト済み）
