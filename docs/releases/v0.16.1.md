# Cm v0.16.1 リリースノート

**前バージョン:** v0.16.0

## 🎯 テーマ: v0.16.0のバグ修正

## 🐛 バグ修正

### implメソッドのデフォルト引数が機能しない問題を修正

- **HIR loweringがメソッド・コンストラクタ・演算子・インターフェースシグネチャのパラメータで `default_value` を落としていた問題を修正**: 補間内のメソッド呼び出しで省略した引数が型のデフォルト値（0）で補完され、誤った計算結果になっていた
- **型検査のメソッド引数個数チェックがデフォルト引数を考慮していなかった問題を修正**: 文としての省略呼び出し（`c.add(5)`）が「expects 2 arguments, got 1」エラーになっていた。`MethodInfo` に必須引数数を導入し、impl・interface・enum・スライスimplの全検査経路を統一ヘルパーで検査する（引数不足は「expects 1 to 2 arguments」形式のエラーを維持）
- 回帰テスト追加: `tests/common/functions/default_args_method.cm`（文・補間・複数デフォルトの部分省略を全バックエンドで検証）

### コンパイラビルドの警告をゼロ化

- **`make build`（-Wall -Wextra -Wpedantic）で出ていた警告27件を全て解消**
- switch網羅漏れの修正: `unary_op_str` の `Try`・`token_kind_to_string` の `MaskedBinLiteral`/`PlusColon`・match網羅性検査の `Masked`/`Type` パターン（網羅性の強制はbool/enumのみ対象のため追跡不要を明示）
- 集約初期化のフィールド漏れの修正: `SVPort::init_value`（ポート構築8箇所へ明示的な空初期値を指定）・`HirParam::default_value`（宣言loweringの10箇所。上記デフォルト引数バグの温床だった）

### ドキュメント・CLIの記載修正

- READMEの現行化: SystemVerilogバックエンドの記載追加（特徴・パイプライン図・CLI例・ドキュメントリンク）、Result/Optionエラーハンドリングの特徴追加、テスト構成を3層+全バックエンドスイートの現行内容へ更新、古いテスト件数の記載を削除
- `cm help` の `--target` 一覧に `sv` を追加（SVオプションは記載済みなのにターゲット一覧から漏れていた）

### SVバックエンド: 出力ポートの宣言初期値の欠落を修正

- **`#[output]` ポートの宣言初期値が生成SVへ出力されず、条件付き代入しか持たない出力ポートがシミュレーションでX（不定値）のまま残る問題を修正**: 内部レジスタと同じ方針で電源投入時初期値としてポート宣言に出力する（例: `output logic [31:0] max_seen = 32'd7`）。インスタンス出力に接続されたポートは連続駆動されるため従来どおり初期値を付けない
- 発見経緯: 実回路（CmCPUリポジトリのHDMIタイトル描画）の範囲外書き込み回帰テストで、X初期値の出力ポートを含むassertがX楽観性（`if (!(x == 期待値))` が偽になる）により常にPASSし、バグを検出できなかった
- 回帰テスト追加: `tests/regression/cases/sv/module/output_port_initial_value.cm`（条件付き代入のみの出力ポートに初期化子が付くことを検証）
