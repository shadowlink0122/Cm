# Cm v0.16.1 リリースノート（開発中）

**前バージョン:** v0.16.0

## 🎯 テーマ: v0.16.0のバグ修正

## 🐛 バグ修正

### SVバックエンド: 出力ポートの宣言初期値の欠落を修正

- **`#[output]` ポートの宣言初期値が生成SVへ出力されず、条件付き代入しか持たない出力ポートがシミュレーションでX（不定値）のまま残る問題を修正**: 内部レジスタと同じ方針で電源投入時初期値としてポート宣言に出力する（例: `output logic [31:0] max_seen = 32'd7`）。インスタンス出力に接続されたポートは連続駆動されるため従来どおり初期値を付けない
- 発見経緯: 実回路（CmCPUリポジトリのHDMIタイトル描画）の範囲外書き込み回帰テストで、X初期値の出力ポートを含むassertがX楽観性（`if (!(x == 期待値))` が偽になる）により常にPASSし、バグを検出できなかった
- 回帰テスト追加: `tests/regression/cases/sv/module/output_port_initial_value.cm`（条件付き代入のみの出力ポートに初期化子が付くことを検証）
