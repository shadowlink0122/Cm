## v0.16.0 — SVバックエンドの機能充実

詳細: [v0.16.0ロードマップ](v0.16.0/roadmap.html)（実装設計 01〜04）

- モジュールパラメータ `#(parameter)` + 階層Stage 3（パラメタライズドIP）
- `#[sv::pin]` + `--emit-constraints`（.cst/.tcl生成）
- トライステート（'z）・CDC同期化プリミティブ
- ビットスライス構文・casez/unique case
- WIDTH系lint警告解消の継続、非サポート構文の明示エラー化

## v0.17.0 — バックエンド意味論の完全一致

「どのバックエンドでも同じCmプログラムが同じ答えを出す」を完成させる。

- interface動的ディスパッチの全実行系対応（JSポインタ経由・interpreter。MIRレベルのfat struct + 関数ポインタ lowering への移行）
- JSバックエンドのポインタ完全対応（現在❌の領域の解消 or 明示エラーの網羅）
- cross_backend_semantics スイートの体系的拡充（浮動小数点・文字列・オーバーフロー・キャストの全組み合わせ）
- 文字列補間の旧テキストハンドラ群を本物の式パーサ経路へ全面移行（型情報の完全な伝播。ミニパイプラインの廃止）
- エラー処理方針 Phase B〜D の完了（error_handling_policy.md）

## v0.18.0 — 言語仕様の完成と凍結

仕様と実装の乖離をゼロにし、以後の破壊的変更を禁止する。

- **自由関数オーバーロードの最終判断**（導入するなら `overload` 構文で実装、しないなら仕様から削除して現行診断を正式化）
- **ライフタイム/借用検査の完成**（現在は宣言のみ。interface値の借用検査を含む）
- string型の完全化（SVの長さ型化を含む、全バックエンドでの意味論統一）
- CANONICAL_SPEC / cm_grammar を実装と完全同期させ、仕様適合テストスイートを作成
- 予約語・構文の最終整理（未使用予約の解放または確定。ユーザー定義derive向けの `Self`・`fields`・`derivable` の予約を含む: [v0.16.0設計11](v0.16.0/11_user_defined_derive.html)）

## v0.19.0 — 開発体験（ツールチェーン）

- **LSP（言語サーバ）**: 定義ジャンプ・補完・診断のエディタ統合（VSCode拡張をシンタックスハイライトからLSPクライアントへ拡張）
- **パッケージマネージャ** `cm pkg`（init/add/publish、libs/の外部化）
- デバッガ統合（DWARF情報の充実、lldbフロントエンド）
- ドキュメント生成（doc comment → HTML）
- インクリメンタルコンパイル（archive/unimplemented/incremental_compilation.md の再評価）

## v0.20.0 — 安定化・互換性保証（1.0 RC）

- 全既知バグゼロ・全スイートの網羅率目標達成（行カバレッジ計測の導入）
- 後方互換性ポリシーの制定（SemVer運用・非推奨化プロセス）
- パフォーマンスベンチマークの回帰ゲート化（benchmarksのCI組み込み）
- セキュリティ/ファジングテスト（パーサ・プリプロセッサ）
- v1.0向けドキュメント全面レビュー（チュートリアル・仕様・リファレンス）

## v1.0.0 — 正式リリース

- 仕様凍結の宣言と互換性保証の開始
- 全バックエンド（native / WASM / JS / SV / interpreter）のサポートレベルを明文化（Tier 1/2）
- 1.0リリースノート・移行ガイド
